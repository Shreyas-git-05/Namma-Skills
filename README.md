# NammaSkill

## Project Title

NammaSkill - Skill Development and Learning Android Application

### Problem Statement

Many students and job seekers struggle to discover skill development opportunities, learning resources, and career guidance in one centralized platform. NammaSkill is an Android application developed to simplify skill learning, course discovery, and career growth through an easy-to-use mobile interface.

---

# Project Overview

NammaSkill is an Android application built using Android Studio. The application provides users with access to courses, stories, maps, and profile management features in a structured and user-friendly interface.

The project focuses on improving accessibility to learning resources and helping users explore skill-building opportunities efficiently.

---

## Features

* User-friendly Android application interface
* Course browsing and learning modules
* Story and content section
* Interactive navigation using fragments
* Profile management
* Organized application structure
* Database integration support
* Responsive layouts and reusable components

---

## Tech Stack

* Java
* Android Studio
* XML Layouts
* SQLite / Room Database
* Gradle Build System
* Android SDK

## Installation Steps

## Prerequisites

Make sure the following software is installed:

* Android Studio
* Java JDK
* Android SDK
* Gradle

---

## Steps to Run the Project

1. Download or clone the repository:

```bash
git clone https://github.com/Shreyas-git-05/Namma-Skills.git
```

2. Open Android Studio.

3. Click:

```text
Open Existing Project
```

4. Select the `NammaSkill` project folder.

5. Wait for Gradle synchronization to complete.

6. Connect an Android device or start an emulator.

7. Click:

```text
Run ▶
```

8. The application will build and launch successfully.

---

## Run Command

To build the project manually:

```bash
./gradlew build
```

To generate APK:

```bash
Build > Generate APK
```
